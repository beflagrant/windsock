# Security Policy

## Supported versions

Security fixes go into the latest release only.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/beflagrant/windsock/security/advisories/new)
or by email to rave@beflagrant.com.

We'll acknowledge the report within a few business days and keep you posted
until it's fixed and released.
